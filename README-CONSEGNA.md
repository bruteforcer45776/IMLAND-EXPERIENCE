# IMLAND Experience - codice completo

Cartella pronta per essere aperta in VS Code e consegnata a un collaboratore.

## Contenuto

- `src/`: codice sorgente del sito.
- `public/`: asset pubblici, immagini, favicon, manifest, sitemap e robots.
- `supabase/`: configurazione e migrazioni database presenti nel progetto.
- `.openai/hosting.json`: configurazione Sites trovata nel progetto.
- `package.json` e `package-lock.json`: dipendenze e script.

Non sono inclusi `node_modules`, build temporanee, cache o cartelle di output pesanti.

## Come aprirlo

1. Apri VS Code.
2. Vai su `File` > `Open Folder`.
3. Seleziona questa cartella: `IMLAND Experience - codice completo`.

## Comandi utili

Da terminale dentro questa cartella:

```bash
npm install
npm run dev
npm run build
```

## Nota importante

Questa e' una cartella sorgente continuabile. La pubblicazione sul sito live Sites richiede accesso al progetto Sites corretto. Se il progetto live non e' accessibile dall'account corrente, il codice resta modificabile e costruibile localmente, ma la pubblicazione va fatta dall'account/progetto che possiede il sito live.
